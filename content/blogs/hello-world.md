This is a sample post. Every Markdown file in `content/blogs/` becomes a page
at `/blogs/<file-name>/`.

## Writing a post

Start the file with the block of settings you see at the top of this one
(title, date, description, tags), then write the post in Markdown below it.

- Lists, **bold**, `code` and [links](https://example.com) all work.
- Add `coverImage: "/blogs/my-cover.png"` to show a cover image, and put the
  file in `public/blogs/`.
- Set `featured: true` to show the post on the home page.
